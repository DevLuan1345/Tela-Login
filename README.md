## 🔐 Tela de Login

Este projeto consiste no desenvolvimento de uma interface moderna de tela de login, criada com foco em design limpo, organização e boa experiência do usuário.

A página apresenta campos essenciais para autenticação, como usuário e senha, além de elementos visuais que tornam a navegação mais intuitiva e agradável. O layout foi estruturado para ser simples e funcional, permitindo fácil adaptação para diferentes tipos de sistemas.

Um dos destaques do projeto é a utilização da API Unsplash, responsável por gerar imagens de fundo dinâmicas e de alta qualidade, deixando a interface mais atrativa e moderna.

## 🚀 Tecnologias utilizadas

- HTML5 🟧
- CSS3 🟦
- API de imagens (Unsplash) 📌

## 🎯 Objetivo

O principal objetivo deste projeto é praticar a criação de interfaces front-end, simulando uma tela de acesso comum em sistemas web, reforçando conceitos de estruturação de layout, estilização responsiva e integração com APIs externas.

## 💡 Funcionalidades

Campos de login (usuário e senha)
Imagens de fundo dinâmicas via API
Design moderno e organizado
Interface amigável e intuitiva

## 📱 Responsividade

A tela foi desenvolvida pensando em adaptação para diferentes dispositivos, garantindo uma boa visualização em telas menores.
